# UI copy cleanup prompt

Simplify this page’s wording while preserving its usefulness.

First identify the questions it answers, the data users need, and the actions they can take. Preserve useful values, timestamps, identities, counts, previews, links, and controls.

Remove redundant explanations, repeated labels, obvious instructions, and internal jargon. Prefer deletion over rewriting. Keep essential warnings and recovery guidance brief and close to the relevant action.

Don’t remove or hide useful information merely to make the page shorter. If its value is uncertain, retain it and flag it for review.

Briefly state what you’ll preserve and remove, then implement in one pass. Verify populated, empty, and error states on phone and desktop. Check that useful information remains accessible—not just that unwanted wording disappeared.
