# Planning Backlog

This directory collects early-stage planning artifacts that have not yet been
accepted as active implementation work. The files retain their original names
and content; this index groups them only to make selection and triage easier.

When an item is selected, move its planning work through the feature
development process and place a multi-artifact feature in its own directory
under `docs/plans/`. Move completed feature cycles to `docs/plans/archive/`.
