Reported symptom:
./v3 import-instance zenmemes.com downloads and extracts successfully, then fails
while planning with Invalid header line: -----BEGIN PGP SIGNATURE-----.

Reproduction:
Downloaded 612797 bytes from https://zenmemes.com/downloads/repository.tar.gz.
Archive SHA256: d0549e3c4bb072147b4a3d5850456d242acdc5684ee49e6de2e0b3aba16fedf0
Used the production downloader/extractor and an isolated destination in /tmp.
Exact exception reproduced at ContentImportPlanner.php:56 through loadThreadLabel,
ThreadLabelRecordParser and GenericTextRecordParser. Accepted signature example:
records/thread-labels/thread-label-24f56ce40a894d1002c9085d7dc28e18.txt.asc
No source records, signatures or application runtime content were repaired/deleted.

Rubber-duck trace:
1. Archive validation correctly accepts a detached signature next to its record.
2. describe() recognizes it, validates its parent and assigns a signature identity.
3. The later label-removal policy checks only the directory prefix and import state.
4. Both the label and its accepted signature satisfy that condition.
5. loadThreadLabel() receives the signature path and sends ASCII armor to the text
   header parser. The parser correctly rejects the armor; weakening it is wrong.
6. This call is outside describe()'s record-rejection handling, so planning aborts
   before the durable import journal or canonical writes are prepared.
7. The same second read omits the destination signing-key fallback. Even after
   excluding signature paths, a valid label whose key exists only locally fails.

Repair:
Use ArchiveRecordCatalog::isRecordPath as well as the family prefix before applying
label-specific policy. Signatures continue to inherit parent exclusions/rejections
through the existing dependency propagation. Give the second label read the same
legacy-metadata requirement and destination signing-key fallback as describe().
Do not catch-and-ignore unexpected exceptions, remove signatures, rewrite signed
bytes or bypass signature validation. No new dependency, core schema or UI change.
