9 · Messages

Private, end-to-end encrypted conversations between approved members. The list should read like any messaging app, even though every preview is decrypted in the browser.

templates/pages/private_message_list.php · partials/private_message_conversation_row.php · templates/pages/private_messages.php (legacy inbox/sent)

Wording

  • Authentication Required — Authenticate an approved browser identity to view private messages.“Messages are for approved members”, a status-specific line and one button: Set up account, or Back up while you wait.
  • Encrypted message · Retry previewA lock icon and “Couldn’t decrypt preview” with a Retry icon, only on the affected row.
  • Reload Messages · Retry loading · Retry unread statusOne inline banner, “Couldn’t load messages. Retry”, shown only on failure.
  • Enable JavaScript to load more conversations and decrypt previews.Kept. It is the honest no-JS recovery message.

Arrangement

  • Desktop is two panes: conversations on the left, the open conversation on the right. Phone is a list that pushes to the conversation (mockup 10).
  • Each row: avatar, name, time, a 2-line decrypted preview and an unread dot. A “You:” prefix marks your own last message.
  • The legacy Inbox / Sent mailbox pages fold into conversations; nobody needs to browse by direction.
  • A compose icon (new message) in the header opens a member picker.

Flow

  • Unapproved members don’t see the Messages tab (same rule as today’s nav); anyone arriving by link lands on an explanation that names their actual next step, instead of a dead end.
  • Previews decrypt progressively. Rows show a shimmer, then text, and never the word “Decrypting…” repeated down the list.
  • “Load more” becomes automatic as you scroll, with a button fallback.
