Arrangement

  • The root post is unboxed, like an article: title, then author, then body. Replies sit in one grouped list.
  • Posts that only apply a tag (#pin, #pinned) render today as empty reply cards with Reply/Like/Flag. They collapse into one-line activity entries.
  • Same-author continuations (within 15 minutes) keep their merge behavior, shown by dropping the repeated avatar and name.
  • Operators see Post analysis and the Codex handoff in a disclosure under the post, rather than inline among the reader controls.
  • The reply composer docks to the bottom of the viewport. This fixes the reported bug “The textarea is off screen when I focus it”.

Flow

  • Replying to a specific post stays on the page. The dock gets a “Replying to …” chip and the parent is highlighted, instead of navigating to /compose/reply. That route remains as the no-JS fallback (mockup 5).
  • Like shows a count and a filled heart. Today it becomes a disabled “Liked” button. Proposal: allow unlike. Reaction records are append-only, so this needs a retraction record and a spec change.
  • Flag asks for confirmation in a sheet, because flagging is visible to moderators. Today it is one stray tap.
  • An agent request shows progress in the thread where the reply will appear. Failures say why and offer Retry only when the user can fix it; operator-only fixes say so.
