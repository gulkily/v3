11 · Tools

The launcher for 16 utilities, from personal ones (Outbox) to operator-only ones (Feature Flags). People should find their tool by what it is for.

templates/pages/tools.php · partials/tools_nav.php · Tools/ToolsPageSupport.php · public/assets/theme-nav-icons.css

Wording

  • Descriptions are cut to one short line that says what the tool is for. Examples:
  • Classic three-pane newsreader view of the whole board - folders, thread list, and preview.Three-pane newsreader view
  • Portable downloads of the repository and current read-model database.Download the site’s data
  • Privacy-preserving recent aggregate visits, client estimates, and authenticated-user counts.Aggregate visit counts
  • System StateSystem status
  • ↗ arrows on Activity, Forte, Offline Reading, Platform Docs, AccountRemoved. Every tile opens a page.

Arrangement

  • Today the page shows every tool twice: a three-row button bar, then the same list with descriptions. One grid replaces both.
  • Tools are grouped by who uses them. Your device: Outbox, Offline reading, Bookmarklets. Reading: Activity, Forte, Platform docs. Community: User access, Visitor statistics. Operator: Feature flags, System status, SQLite viewer, Backup, LLM exchanges, Fastmod.
  • Account leaves Tools; it lives in the account menu.
  • On phone, tiles are two-up with descriptions hidden. The Tools subnav bar inside each tool becomes a back link to Tools.

Flow

  • Tiles show live counts where they help decide: Outbox (2 queued), User access (3 waiting).
  • Proposal: hide groups the viewer can’t use (Operator, for non-operators) rather than showing them and then refusing. This needs a per-tool access check in ToolsPageSupport.
  • Implementation: tile icons reuse the Tools launcher mappings in theme-nav-icons.css; check Word97, Chicago and Midnight.
