Arrangement

  • A compact list with one 56px row per person, replacing 150px cards. All 38 members fit in about two screens instead of eight.
  • A search field filters the list as you type. The data is already on the page, so no server change is needed.
  • Sort by Activity (the current order) or Name.
  • Pending approvals live beside the directory instead of at an unlinked URL (/users/pending).

Flow

  • Approving someone happens in the row. Proposal: the row shows “Approved · Undo” for about 5 seconds, and the signed approval record is published only after that window closes. A published approval is permanent, so Undo has to come before publication.
  • Each pending row shows the person’s first post, so approvers can judge without opening a new page.
