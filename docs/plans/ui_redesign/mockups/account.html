8 · Account

Your identity lives in this browser as a keypair. The page should make one thing obvious in each state: start, wait for approval, or protect what you have.

templates/pages/account_key.php · assets/browser_signing.js · assets/key_backup_ui (ForumKeyBackupUI)

Wording

  • Account KeyAccount
  • Not set up yet · Signed in as guest · Fingerprint: No key yet · Set up this browser“Pick a name to start posting”, with a name field and Continue. Guests don’t need the words fingerprint or key yet.
  • Choose username (separate button, then a browser prompt)Name, an editable row in the account list.
  • Clear identity / Clear Saved Keypair“Remove from this browser”. One action, not two, with its consequence stated in the confirmation.
  • Back up or restore · Keys · Storage and privacyBack up account · Restore from backup · Advanced (keys, linking, storage)
  • Download text backup / Download Starfield PNGFormat: Text file or Starfield image. One Download button.

Arrangement

  • Three states each get their own top card: Guest (pick a name), Waiting for approval and Approved. Today one card shows “Not set up yet” with empty fields.
  • The “Not backed up” warning sits at the top whenever there is no backup. This is the most important data-loss consequence on the site: clearing site data loses the account.
  • Raw keys, Copy Private Key, Link a public key, identity hint and cookie details move under Advanced. “Never share this” stays beside the private key.
  • The fingerprint is shortened (first and last 4 groups) with Copy; the full value is under Advanced.

Flow

  • Set up: name, then Continue. The keypair is generated and published in the background, and the card moves to Waiting for approval. This removes the separate “Set up this browser” and “Choose username” steps and both window.prompt dialogs.
  • Back up: a sheet with passphrase, confirmation, a strength meter, a format choice and Download. Afterward the warning becomes “Backed up Oct 24”. Proposal: record the last backup date locally, since nothing tracks it today.
  • Remove: a confirmation states the consequence (“Without a backup you can’t post as ilyag again”) and offers Back up first. The existing Undo link remains afterward.
  • Errors appear inline in the relevant row with a recovery action, e.g. “Couldn’t publish your key. Retry”.
