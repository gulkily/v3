Starting a thread. Write first and decide the details later. A first-time poster should never meet a browser dialog or a wait they didn’t ask for.

Wording

  • New thread · Body · Create threadNew post · Title (optional) · Post
  • Subject & tags generalA “# general” tag chip in the toolbar. The subject becomes the Title line at the top.
  • Event (disclosure) → Event date / Event time / Event location / Event linkAn “Event” toolbar button that inserts a card with Date, Time, Place and Link.
  • You may be asked to choose a username.“Posting as guest · Choose a name”, inline in the composer before you post.
  • Create thread anonymously / Remove timestamps / Clear fields / Save thread to OutboxThe ··· menu offers Post anonymously, Save to Outbox, Remove timestamps and Discard draft.

Arrangement

  • The order follows how people write: Title, then Body, then tools (image, tag, event), then the identity line, then Post.
  • Leaving Title empty keeps today’s behavior: the first line becomes the title. The placeholder previews this (“Title — or we’ll use your first line”).
  • On phone this is a full-screen sheet with Cancel and Post in the header bar, so the keyboard never hides the main action.
  • “Remove unsupported characters” stays a just-in-time inline warning under the affected field. It is a recovery action and must stay visible.

Flow

  • First post: today the user writes, presses Create thread, gets a native window.prompt("Choose your username:"), then waits for “Generating browser keypair…” and “Publishing your public key…”. This was reported in the thread “First of all new account bootstrapping is unacceptably slow”.
  • New flow: the name field sits in the composer. Key generation starts in the background when the composer opens, so Post only has to sign and send.
  • Offline: Post becomes “Save to Outbox” with one line explaining when it will send. Today Save to Outbox is hidden in a menu, and a failed submit shows “load failed”.
  • Drafts autosave as they do today. Cancel on a non-empty draft asks “Keep draft / Discard”.
