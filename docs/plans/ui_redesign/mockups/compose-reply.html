Arrangement

  • The parent post becomes a light quote above the field instead of a full boxed card. Long parents clamp to 4 lines with “Show more”.
  • It uses the same composer component as New post, minus Title, Tags and Event, so the two never drift apart.

Flow

  • After posting, return to the thread scrolled to the new reply, highlighted briefly. This matches today’s data-created-post-id behavior.
  • An identity line and the first-post name step work the same as in mockup 4.
