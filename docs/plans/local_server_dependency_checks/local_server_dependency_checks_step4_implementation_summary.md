## Stage 3 - Optional degradation and reliable shutdown
- Changes: added nonblocking warnings for intl, PCNTL functions/constants, terminal `shell_exec`, and `stty`; guarded terminal sizing/restoration and kept plain fallback logs. The Bash launcher supervises the PHP wrapper through a control pipe so SIGINT/SIGTERM and launcher exit permit child cleanup without PCNTL. PHP cleanup is registered for error exits and uses bounded termination, with forced child termination if graceful termination fails. Missing intl guidance explains existing combining-mark rejection.
- Verification: shell regressions and Bash/PHP 8.1 syntax checks passed. Real PHP 8.3 lifecycle checks covered 20 combinations: normal runtime, missing PCNTL functions, disabled `shell_exec`, both disabled, and missing `stty`, each with terminal/redirected output and SIGINT/SIGTERM to the foreground process group. Every case served an HTTP request, wrote plain logs, exited successfully, and left no listener. PHP 8.1 Unicode policy/risk and logging tests passed: 25 run, 0 failures. Required-failure matrix remained passing; `git diff --check` passed.
- Notes: terminal cosmetics stay optional. Lifecycle control needs Bash (already the launcher interpreter), not a new installed signal utility. The test packages include PCNTL statically, so absent support was exercised by disabling its functions. Runtime warnings do not change diagnostic success status.
