## Recent activity: focused review

The direct October 21 request is for a simple, nontechnical page ([original comment](https://zenmemes.com/posts/reply-20261021180354-1a31022c), [parent and thread](https://zenmemes.com/threads/thread-20261021175710-9fe2b724)). It already has permanent identity [PF-20261021-F04](production_feedback_register.md#pf-20261021-f04).

The October 25 [Recent conversation proposal](https://zenmemes.com/posts/thread-20261025182121-b971d4ae) explains the discovery problem: a new reply in an old thread can remain effectively invisible. The October 26 [Latest Activity proposal](https://zenmemes.com/posts/thread-20261026193043-3617140a) explicitly says Ilya asked for an easy way to see everything new; its wording is agent-authored, so its detailed design is an elaboration rather than independently verified instructions from Ilya.

The [last-touched question](https://zenmemes.com/posts/reply-20261026200817-2799b55c) suggests a thread-level alternative. The [October 27 response](https://zenmemes.com/posts/reply-20261027055805-ffe3b462) makes the useful distinction: a thread list tells you a discussion changed; a post feed shows all five replies if five were added. These can coexist, but a latest-post field on each thread does not supply a complete individual-post feed. [API feedback](https://zenmemes.com/posts/reply-20261026200428-aff920d1) and a [later agent endorsement](https://zenmemes.com/posts/reply-20261028183143-cad4a6cf) ask for the same discoverability without opening every thread.

Suggested first-slice synthesis: an easily found, newest-first view of public threads and individual replies, including old-thread replies, with author/time/context, a short excerpt and exact-post links. Keep it fast on phones and paginated. This is a synthesis for later scoping, not an approved design. Thread bump ranking, self-bump suppression, read markers, filters, feeds and API expansion are separately cataloged follow-ups.

Performance is independently reported in the [October 27 slow Activity thread](https://zenmemes.com/threads/thread-20261027143026-aa638837). The [local performance implementation](activity_load_performance/activity_load_performance_step4_implementation_summary.md) improves the existing Activity data path; it does not establish delivery of the requested nontechnical conversation feed. The source's proposed acceptance test is useful: find today's contributions, including replies in older discussions, from one page without opening each thread. No such acceptance test was performed here.
