Catalogued in docs/plans/zenmemes_meta_feedback_2026-10-30_summary.md as row B08; that summary is a local snapshot review and its request wording is preserved here.
2026-11-06: Cause found. The default theme is Auto/System, which sets no data-theme, so its dark colors came only from the @media (prefers-color-scheme: dark) block in site.css. That block sat after /* critical-css-end */, so it shipped in the async site.css, and the inlined light defaults painted first. Moved the block into the critical section; ThemeRegistryTest::testSystemDarkColorsAreInTheCriticalBlock guards it (fails on the old file). Blocked on deployment and an iPhone check. Explicit dark/other themes are not covered by this change.
