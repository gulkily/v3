Title: Last import can show the wrong run for two imports in one second
Kind: bug
Workflow: ready

Request:
InstanceImportStatus picks the newest run by directory name, and the name carries a time to the second plus a random suffix. Two imports that start within the same second sort by the random part, so Tools → Import's "Last import" row can show the earlier run's counts.

Sources:
- Session: Claude chat with the maintainer, 2026-11-22

Done when:
Two imports started within one second show the later run as the last import.
