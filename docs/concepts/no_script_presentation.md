# No-script presentation

Purpose: Pages are truthful when scripts cannot run. Controls that only work with scripts are not shown, and copy that only comes true with scripts is swapped for copy that is true without them. Server HTML stays static and first paint is final.
Scenario: A visitor with JavaScript disabled reads the board, pages through it, opens threads and posts anonymously through ordinary links and forms. They see no Like/Flag or View query buttons, because those need scripts. On a members-only instance the 401 page reads "Members only" with links to the browser key and lobby, instead of "Reconnecting". The decision happens in CSS, in the first-paint part of `site.css`: `@media (scripting: none)` hides script-only controls (the `.requires-script` utility or a specific selector), and `@media (scripting: enabled)` hides `.without-script` copy. Browsers without the `scripting` media feature, including very old ones, see both; making old engines readable is separate work (the Windows ME compatibility cycle).
