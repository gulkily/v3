# Theme navigation icons

Purpose: Give icon themes a 16px glyph on each navigation destination without changing markup or server HTML: pixel art for Word97, Chicago and Midnight, smooth lines for Gloss, Gloss Dark and Engagify.
Scenario: A reader in an icon theme sees a glyph before the label of every main navigation link, Tools bar link, Tools launcher button, Bookmarklets button and launcher group heading. The glyph is chosen in CSS from the link's `href` (board filters use `data-nav-key`, bookmarklets `data-bookmarklet-kind`, launcher group headings `data-shape`), so adding or renaming a destination means adding or moving one rule keyed to its link in each set, for both the launcher button and the Tools bar link where the destination is a tool. Every other theme shows the same markup as text only. The theme menu never receives icons.
Sources: [icon stylesheet](../../public/assets/theme-nav-icons.css) (the `:root:is(...)` theme list at the top adds a theme to the set), [the rule to keep icons current](../../AGENTS.md#navigation-icons), [launcher matrix test](../../tests/browser/tools_launcher.mjs) (asserts a non-empty glyph on each tool button, bar link and group heading in the five icon themes), [set parity test](../../tests/NavIconSetsTest.php) (both sets name the same destinations).

Group heading glyphs: a monitor (device), an open book (reading), the Users glyph (community) and a gear drawn mid-grey with a white ring so it reads on light and dark panels (operator). Account's Tools bar rule remains in the stylesheet although Account is no longer a tool; its main navigation rule still applies.

Tool glyphs added later keep the same 16px grid; Deploy (an arrow rising out of a tray) follows Operations in the operator group. Calendar is a page-a-day block with a red header. On phones the account menu is More, so its person glyph becomes a three-line list (see [navigation slots](navigation_slots.md)); the More panel's destination links take their glyphs from the same `href` rules as the bar.

Two sets share the sizing rules, which list all five icon themes; each set's glyph rules list only its own themes. The smooth-line set draws 1.5px violet strokes over a lavender fill. `site.css` (the phone More tab) and `tools.css` (the Bookmarklets drag handle) keep their own lists of icon themes, which must name a new icon theme too.
