# Thread activity

Purpose: Keep a thread's conversation to replies with something to say, and put its bookkeeping (hashtag-only replies, likes and flags) in one collapsed place.
Scenario: Behind `FORUM_THREAD_ACTIVITY_DRAWER_ENABLED` (off by default), a reply whose body is only hashtags, with no other text, leaves the thread page's conversation unless a shown reply answers it. A collapsed "Activity (N)" drawer after the last reply, before the reply box, lists each such reply as "e tagged #bug · date", linking to the reply's own page. With [`title:` lines](../../src/ForumRewrite/Support/TitleDirective.php) on (`FORUM_TITLE_DIRECTIVE_ENABLED`), a reply that is only one `title:` line, with or without labels, leaves the same way and is listed as "e posted title: New name · date" (2026-11-18, [one-shot](../plans/title_only_activity/title_only_activity_one_shot.md)). It then lists, for the root and each reply with reactions, "Root post — Liked by a, b · Flagged by c" or "Reply by d — …". Each post group links to the post's Records list when [post record list](post_record_list.md) is on, otherwise to the post. With Post records on, each name in a like or flag list links to the record that added it (`/records/<Record-ID>`, the newest `add` when there are several); without it, or when no record is found, the name links to the profile. With nothing to list, there is no drawer.
Sources: [hashtag rule](../../src/ForumRewrite/Support/ThreadLabels.php), [leaf filter](../../src/ForumRewrite/ReadModel/TagOnlyLeafFilter.php), [entries](../../src/ForumRewrite/View/ThreadActivity.php), [drawer partial](../../templates/partials/thread_activity_drawer.php), [thread page](../../templates/pages/thread.php), [plan](../plans/thread_activity_drawer/thread_activity_drawer_step3_development_plan.md)
Boundary: Display only. The reply, its thread labels and its own page stay as they are; nothing is stored or signed differently. "Tag-only" uses the same rule that turns hashtags into thread labels, so a body counts only when every hashtag is a valid label; quoted (`>`) lines are ignored, and a subject, a thread type, agent-response metadata or a retraction keeps the reply in place. Actors come from [signal actors](../../src/ForumRewrite/ReadModel/SignalActors.php), so the drawer names match the signal lines. Their record IDs are not in the read model: with both flags on and a reaction to show, the thread page finds them with one `git grep` over the reaction and thread-label records ([plan](../plans/thread_activity_record_links/thread_activity_record_links_one_shot.md)), about 85–110 ms against 13,000 records. Reactions have no time in the read model, so entries are grouped by post, not shown as a timeline. Only `/threads/<id>` has the drawer; Forte, static detail pages and post pages are unchanged. If building the drawer fails, the page shows every reply and no drawer.
Related fold (2026-11-16): on a [pledge campaign](pledge_campaign.md), a bare `withdraw` reply that took effect also leaves the conversation, through its own [filter](../../src/ForumRewrite/ReadModel/WithdrawLeafFilter.php) that runs before this one. It is not listed in the drawer and does not depend on this flag; the withdrawn pledge links to it.
