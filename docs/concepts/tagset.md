# Tagset

Purpose: Let a thread tag unlock extra tags on the thread's replies, with optional exclusive groups that act as one state.
Scenario: `resources/tagsets.txt` gives `meta` the exclusive group resolved, closed, open. On a reply in a `#meta` thread (authored tag, label or Fastmod tag) Resolved and Closed appear beside Like and Flag; a tap writes an ordinary post reaction. The latest mark from an approved key sets the reply's state, ordered by Action-At; unapproved marks are stored, not counted. Resolved and closed replies fold to one line (author and date, then the state label, then the first words) that any reader can expand; Reopen (tag `open`) unfolds. The opening post takes the same tags (`Target: reply, root`); it shows its label after the byline and does not fold. `get_post` reports `Resolution:` and `get_thread` prefixes `(resolved)` or `(closed)`.
Sources: [tagsets file](../../resources/tagsets.txt), [loader](../../src/ForumRewrite/Support/Tagsets.php), [write check](../../src/ForumRewrite/Write/LocalWriteService.php) (`unlockedPostTag`), [state](../../src/ForumRewrite/ReadModel/PostResolution.php), [buttons](../../templates/partials/post_unlocked_tags.php), [fold](../../templates/partials/post_card.php), [opening post](../../templates/partials/thread_root_card.php), [agent docs](../reference/agent_api.md#reply-resolution-tag-unlocks).
Boundary: Unlocked tags never change scores or Fastmod. Targets are `reply`, `root` or both; board-level thread states and a per-person grant of tags (Pollyanna's unbuilt permission tagsets) are not. Behind `FORUM_TAG_UNLOCKS_ENABLED`.
